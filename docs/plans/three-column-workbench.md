# 三栏阅读工作台方案

> 左侧找内容 · 中间读正文 · 右侧问 AI
>
> 状态：设计提案，尚未实机验证，仓库代码尚未修改。

## A 推荐方案

> **正文优先，助手按需展开**
>
> 在现有双栏上增加可收起的 AI 栏。三栏分别滚动，正文保留完整标题与阅读设置。
> 这是设计提案，尺寸为建议值，尚未实机验证。

## B 三栏分工
| 左栏：文章流 | 中栏：正文 | 右栏：AI 助手 |
| --- | --- | --- |
| 搜索、推荐、关注等现有入口 | 完整标题、作者、正文 | 模型名称、收起按钮 |
| 沿用现有信息流卡片 | 当前阅读内容 | 当前文章及引用范围 |
| 高亮当前选中的文章 | 选中文字后可提问 | 总结本文、解释选段、自由提问 |
| 保留列表位置与加载结果 | 评论、收藏等原有操作 | 流式回答、停止、重试、复制 |
| 沿用现有导航偏好 | 阅读工具栏限定在中栏 | 底部输入框与待发送引用 |

## C 宽度分配
按有效内容区的逻辑 dp 计算。原生侧栏、窗口边框不计入可分配宽度。

| 区域 | 1440dp 示例 | 最小宽度 |
| --- | --- | --- |
| 文章流 | 320dp | 320dp |
| 左分隔条 | 16dp | 16dp |
| 正文 | 728dp | 560dp |
| 右分隔条 | 16dp | 16dp |
| AI 助手 | 360dp | 320dp |

两条分隔条可拖动，并保存用户宽度。最小预算为 1232dp，建议从 1280dp 启用三栏。
宽度不足时切换布局，不把正文继续压窄。关闭助手后，空间还给正文。

## D 窗口自适应
| 条件 | 展示方式 |
| --- | --- |
| 有效宽度不小于 1280dp，且符合现有横屏条件 | 用户打开助手时显示三栏 |
| 符合现有双栏条件，但不满足三栏预算 | 列表与正文双栏，助手作为右侧抽屉 |
| 不符合现有双栏条件 | 保留单栏导航，助手作为独立对话页 |

桌面首次打开助手前保持现有双栏。记住展开选择，但不在打开文章时自动发请求。
建议首次桌面窗口以 1440×900dp 为目标，并受可用工作区限制。恢复窗口时尊重用户尺寸。

## E 切换与返回
- 点击左栏文章，只替换中栏内容，列表保留位置。
- 每篇文章保留独立对话、输入草稿和对话滚动位置。
- 切换文章时停止旧文章的生成，保留已生成文字。
- 回到旧文章时恢复它的对话，不混入另一篇正文。
- 收起助手保留草稿和对话；正在生成时停止并保留部分结果。
- 抽屉与独立对话页可通过返回关闭。
- 常驻右栏用收起按钮关闭，不改变正文返回栈。
- ESC 先交给焦点控件，再按现有窗口返回链处理。

## F AI 上下文与请求预算
右栏顶部始终显示当前文章及本次引用范围。
选中文字后点击“问 AI”，先把选段放入输入区，发送后才请求模型。
“总结本文”使用已加载正文；未选文字的自由提问默认使用当前正文。
正文未加载完成时提示等待，不能把列表摘要冒充全文。

| 用户动作 | 新增请求 |
| --- | --- |
| 打开或切换文章 | 0 次 AI 请求 |
| 展开或收起助手 | 0 次 AI 请求 |
| 点击总结、发送问题或明确重试 | 每次 1 次 AI 请求 |
| 停止生成 | 取消现有请求 |

复用已加载正文，不额外请求知乎详情。
发送时显示模型服务及正文范围。超长正文不得静默截断，可改用选段提问。
第一版不增加联网搜索、跨文章知识库或自动分析。

## G 复用与新增边界
现有 feature:ai 已有配置、消息模型和流式请求接口。
现有“总结本文”支持知乎直答与自定义模型，保留两种选择。
连续问答先使用已配置的自定义模型；未配置时提供现有配置入口。
知乎直答总结接口尚不能视为已验证的多轮聊天协议。

| 复用现有能力 | 新增能力 |
| --- | --- |
| 列表、正文、导航与分隔条交互 | 第三栏及宽度约束 |
| CustomAiConfigFile、ChatMessage、streamChatCompletion | 对话界面及文章隔离状态 |
| Compose Markdown 正文 | 选段进入提问框的交互 |

三栏尺寸与显示状态由主壳持有。
对话按账号、内容类型和内容 ID 隔离，存活时间长于面板组合。
第一版保留应用运行期间的会话；跨重启历史不纳入本版。
新阅读交互仅接入 Compose Markdown。

## H 验收条件
- 检查 1440dp、1280dp、1100dp 和窄窗口的真实页面。
- 拖动分隔条后正文不遮挡，标题仍可完整换行。
- 收起或展开助手不重置正文与文章流的滚动位置。
- A 文章提问后切到 B，再回 A，草稿与对话归属正确。
- 切换或关闭时，旧响应不能写入新文章对话。
- 评论弹层、阅读播放器和输入框不覆盖其他栏。
- 保存最终三栏、收起态与窄窗口截图，验证停止及重试。
